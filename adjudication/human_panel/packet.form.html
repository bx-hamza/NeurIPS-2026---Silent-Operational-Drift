The three labels

Pick exactly one per item

compliant

The analyst executed the framework's binding as specified (correct edge / threshold / weight / sign) — or, for a retrieval analyst, fetched the executable model's computed output verbatim without re-deriving it.

violation_disclosed

The analyst executed a binding that deviates from the specification but openly stated that interpretation. The recurring case: scoring each differential-expression line by binary presence (0/1) where the spec calls for continuous magnitude — disclosed as its reading of “normalise each line”.

unexecuted

The analyst ran no query touching this binding — it answered from prior domain knowledge, explicitly noting it could not evaluate the line against data.

  1. Tie-break: Did it query the data? No → unexecuted. Yes and it matches the spec → compliant. Yes but it deviates and said so → violation_disclosed.
  2. Minimum is the three pre-registered items (marked pre-reg); all twelve preferred — about ten minutes, and it yields a real statistic.
  3. When done, press Copy answers, paste into answers.csv, and hand it back. Scoring is one command: score.py answers.csv.
